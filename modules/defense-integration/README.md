# NIKNOLIG Defense Adapter – Platzhalter

Vorgesehen ist ausschließlich ein eng begrenzter Adapter zur ausdrücklich
autorisierten Kommunikation mit NIKNOLIG Defense. Dieses Verzeichnis enthält
weder Defense-Quellcode noch einen laufenden Adapter. Es schafft keine
gemeinsame Vertrauensdomäne und gewährt keine impliziten Berechtigungen.
