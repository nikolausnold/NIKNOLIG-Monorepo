Vorgesehener Integrationspfad für die Android-App. Hier wurde kein Quellcode
importiert: Ein verifiziertes Quellrepository und dessen gewünschte Revision
liegen nicht vor. Vor einer Integration müssen Android-Kompatibilität,

werden.
