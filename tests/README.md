# Tests – Platzhalter

Es gibt derzeit keine Test-Suites, Test-Runner oder Build-Konfiguration.
Geplante Prüffelder sind Modulgrenzen, Authentifizierung und Autorisierung,
Fehlerbehandlung, Offline-Synchronisation, Geräteintegration sowie
Mehrsprachigkeit und RTL. Konkrete Tests setzen verifizierten Quellcode und ein
festgelegtes Buildsystem voraus.
